Take-aways: backup is gated by the NVMe write (1.64 GB/s, single drive, per-write fsync) — fix with no-fsync / large sequential writes / O_DIRECT / stripe over the 8 idle drives (~5.3×N). Prefetch is gated by the pf→lf load kernel (5.4) (9-month-stale AMD kernel; JIT kernel via PR #25154 is 1.3–5× faster) and the file read (4.89). L1↔L2 is already near the link ceiling.
